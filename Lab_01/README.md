# Лабораторна робота №1

## Варіант 8 — Аналіз банківських транзакцій

### Завдання

Відібрати успішні банківські транзакції,
конвертувати їх суму та застосувати комісію.

Курс, комісія та фільтр мінімальної суми
передаються через Callable.

## Структура

- core.py — чисте функціональне ядро
- app.py — оболонка I/O
- tests/test_core.py — тести
- requirements.txt — залежності

## Запуск

```bash
python app.py
